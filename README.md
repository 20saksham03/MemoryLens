# MemoryLens
AI-powered semantic search engine that transforms screenshots into an intelligent personal memory.

## Problem

Users accumulate thousands of screenshots containing useful information such as
receipts, recipes, shopping products, travel tickets, notes, addresses, and documents.
Finding the right screenshot later is difficult.

## Solution

MemoryLens uses multimodal AI, OCR, intent detection, embeddings, and semantic search
to make screenshots searchable by meaning rather than filename.

## Project Structure

- `frontend/` — Next.js + React frontend
- `backend/` — FastAPI + Python backend
- `docs/` — Architecture and API documentation
